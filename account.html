The Archionary administrator account is reserved for the designated Nemo address.

Create the account only once. This setup is protected by a private bootstrap code configured in Supabase Edge Function secrets.

How to configure first-time setup
  1. Open Supabase project Settings → Edge Functions → Secrets.
  2. Add a secret named ARCHIONARY_BOOTSTRAP_SECRET.
  3. Use a long, random value (at least 32 characters) and keep it private.
  4. Enter that same value here only when creating the account.

Once the account exists, the setup form will no longer work. Use sign-in thereafter.
