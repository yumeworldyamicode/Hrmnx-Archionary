# Archionary

An editorial archive, living encyclopedia, and curated honours collection.

## Project

- Editorial magazine-inspired interface
- Georgia typography throughout
- Custom SVG iconography and brand assets
- Archive, dictionary, honours, and applications
- Administration restricted to a single designated Nemo account: `001@nemo`

## Initial scaffold

This repository begins with a static UI foundation. Authentication, application storage, archive integrations, and administration actions must be connected to a backend before they are operational. Never put administrator credentials or secrets in client-side code.

## Planned pages

- `/` Homepage and discovery
- `/apply` Honour/special-page applications
- `/admin` Restricted administration portal (backend authentication required)
